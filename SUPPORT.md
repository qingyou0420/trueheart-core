# Support

Use GitHub issues for reproducible bugs and feature proposals after checking
the documentation and existing issues. Include the TrueHeart Core version,
Python version, operating system, minimal synthetic code, expected behavior,
and actual behavior.

Never include tokens, credentials, prompts, conversations, databases, logs, or
other sensitive data in a public support request. Replace all data and
identifiers with synthetic values before posting.

Security vulnerabilities do not belong in support issues. Follow
[SECURITY.md](SECURITY.md) and wait for the private reporting channel if it is
not yet available. Support is community-maintained and has no guaranteed
response time.
